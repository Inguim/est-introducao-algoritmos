# 📚 Para novatos

Se você pretende utilizar este repositório como **guia para seus estudos**, é importante entender primeiro como os arquivos estão organizados.

### 🎯 Ordem recomendada de estudo

> **Dedique seu tempo às listas de `ESTUDO`.**
> Os exercícios do `DREDD` tendem a ser mais fáceis e, portanto, você estará melhor preparado para resolvê-los após praticar os exercícios das listas.

---

## 📁 Estrutura de pastas

A estrutura básica do repositório segue o seguinte padrão:

```text
~root
├── week_N/
│   ├── dredd/
│   └── N_solucao.cpp
├── N_solucao.cpp
└── HELPER.md
```

---

## 📂 `week_N/`

Cada pasta `week_N` representa uma **semana específica de estudos**, onde `N` corresponde ao número da semana.

Dentro dela estarão as resoluções dos exercícios relacionados àquela semana.

Os exercícios podem ser provenientes de:

- 📖 Listas de **ESTUDO**;
- 🏫 Exercícios do **DREDD**;

> ⚠️ **Importante:** exercícios originários do DREDD de determinada semana podem estar ausentes devido às regras de restrição da Universidade.

---

## 🏫 `dredd/`

Esta pasta é destinada aos **exercícios realizados em sala de aula**.

Entretanto, devido à limitação de acesso à Internet existente nos laboratórios, **a maioria desses exercícios não estará disponível neste repositório**.

---

## 💻 `N_solucao.cpp`

Cada arquivo `N_solucao.cpp` representa a resolução de um determinado exercício.

Sempre que possível, o arquivo conterá:

1. 📄 **Enunciado do exercício**
2. 💡 **Solução implementada**
3. 📊 **Observação sobre o desempenho**, caso a solução não tenha alcançado 100% de aproveitamento.

### Exemplo de observação

```text
OBS: OBTIVE APENAS X% DE ACERTO NESSA RESOLUÇÃO.
```

Isso significa que a solução apresentada **não necessariamente representa a solução ideal ou definitiva** para o problema.

> 💡 Caso você encontre uma solução melhor para algum exercício, sinta-se à vontade para contribuir através de um Pull Request.
> ⚠️ Programar é uma arte muito relativa a visão de quem produz, logo, podem existir diversas soluções para o mesmo problema.

---

## 🧭 `HELPER.md`

O arquivo `HELPER.md` funciona como um **guia de estudos**, contendo recomendações sobre quais exercícios realizar e em qual ordem.

> ⚠️ **ATENÇÃO**
>
> Esta seção é bastante subjetiva e baseada na minha **interpretação pessoal** sobre a dificuldade e a progressão dos exercícios.
> Portanto, é completamente natural que você discorde de algumas classificações ou recomendações.

### 📊 Classificação dos exercícios

Cada exercício será classificado em uma das seguintes categorias:

|     Nível      | Descrição                                                                                   |
| :------------: | ------------------------------------------------------------------------------------------- |
|  🟢 **Fácil**  | Exercícios introdutórios ou que exigem conceitos básicos.                                   |
|  🟡 **Médio**  | Exercícios que exigem maior domínio dos conceitos estudados.                                |
| 🔴 **Difícil** | Exercícios que exigem maior raciocínio, combinação de conceitos ou técnicas mais avançadas. |

Além da dificuldade, os exercícios estarão organizados buscando manter uma **progressão gradual de aprendizado**.

### 📝 Exercícios fora do escopo

Caso algum exercício esteja presente em uma lista, mas **fuja do conteúdo previsto para determinada semana**, ele será sinalizado no `HELPER.md`.

# 💻 Utilização do código

Você é livre para **estudar, utilizar e se inspirar nas soluções presentes neste repositório**.

Entretanto, caso utilize algum código produzido aqui como se fosse de sua autoria ou queira **republicá-lo em seu portfólio**, peço, por favor, que:

> ⭐ **Dê os devidos créditos a este repositório.**

As soluções presentes aqui foram desenvolvidas de forma independente e **não utilizei IA para a geração dessas soluções**.

Além disso, as listas de **ESTUDO**, apesar de não serem obrigatórias, demandam tempo e esforço para serem resolvidas.

Por isso, peço que esse trabalho seja respeitado ao utilizar ou compartilhar qualquer conteúdo deste repositório.
