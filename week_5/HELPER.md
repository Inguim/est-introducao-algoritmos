# 📊 Classificação

A dificuldade dos exercícios é classificada de acordo com o nível de conhecimento necessário para resolvê-los.

|     Nível      | Descrição                                                                       |
| :------------: | ------------------------------------------------------------------------------- |
|  🟢 **Fácil**  | Exercícios introdutórios que exigem apenas conceitos básicos.                   |
|  🟡 **Médio**  | Exercícios que exigem maior domínio dos conceitos estudados.                    |
| 🔴 **Difícil** | Exercícios que exigem maior raciocínio ou a combinação de diferentes conceitos. |

> ⚠️ **Observação:** a classificação representa uma avaliação pessoal da dificuldade dos exercícios. Ela pode variar de acordo com a experiência de cada pessoa.
